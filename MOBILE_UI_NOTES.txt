CARROM - PORTRAIT MOBILE UI

The compact three-line menu button at the upper right contains:
- Board Design: PREV / NEXT for all eight Classic or Duboo styles.
- CPU Difficulty: CASUAL / STANDARD / EXPERT, selected state highlighted.
- Rules: opens the scrollable rules sheet.
- Restart: starts a new match (or new Duboo board).
- Next Board: appears in the menu when a Classic board ends.

Tap CLOSE or outside the menu to dismiss it. ESC also closes it in browser.
Opening the menu cancels any unfinished pull gesture without firing.

The game status has moved ABOVE the playing board. The only controls
BELOW the board are shot power and the PULL BACK gesture pad.

To shoot: place the striker on the lower baseline; touch PULL BACK,
drag backward to choose direction and power, and lift the same finger.
Short drags cancel. The menu is isolated from touch-shot handling.

The desktop UI now keeps the CARROM title, style caption and mode buttons
inside its scrollable right panel, allowing a larger board. Mobile keeps its
existing portrait header, mode switch and hamburger menu. Gameplay, rules,
physics, CPU, sounds and themes remain unchanged.
