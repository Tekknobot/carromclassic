# Portrait layout patch - October 14, 2026

- Mobile hamburger no longer contains a ScrollContainer. A responsive, centered sheet keeps board style, CPU difficulty, rival bio, Rules, and Restart visible together. Spacing expands on taller screens and compresses on shorter ones.
- Rules on portrait screens now use six readable, non-scrolling sections, with separate Classic and Duboo content. The existing detailed scrollable desktop Rules are preserved.
- Mobile modal sizing uses both width and height, with smaller type and tap-target padding on narrow/short screens. Landscape gameplay and desktop controls are unchanged.
- Opponent bio is retained. The fresh-match reminder is moved to a small bottom caption.
